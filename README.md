# ModAPI plugin for Dify

Source of the [ModAPI](https://modapi.ai) model provider plugin for [Dify](https://dify.ai): chat and embedding models from OpenAI, Anthropic, Google, xAI, DeepSeek, Kimi, GLM, Qwen, MiniMax and more through one ModAPI API key.

- Plugin source: [`modapi/`](modapi/). Setup, requirements and model notes are in [`modapi/README.md`](modapi/README.md); data handling is in [`modapi/PRIVACY.md`](modapi/PRIVACY.md).
- Predefined model files: generated by [`scripts/generate_models.py`](scripts/generate_models.py) from ModAPI's public catalog (`https://modapi.ai/api/pricing`) and vendor-stated limits.
- Install it from the [Dify Marketplace](https://marketplace.dify.ai/) once it is listed.

## Develop

```bash
cd modapi
pip install dify_plugin==0.10.2 pytest requests_mock pyyaml
python -m pytest tests
```

Regenerate the predefined models:

```bash
python scripts/generate_models.py modapi pricing.json model_prices_and_context_window.json
```

where `pricing.json` is a copy of `https://modapi.ai/api/pricing` and the second file is LiteLLM's `model_prices_and_context_window.json`.

Package with the Dify plugin CLI: `dify plugin package modapi`.
